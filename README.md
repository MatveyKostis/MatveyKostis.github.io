# komaru's website

Personal site of Matvey "komaru" Kostis — Python-in-the-browser enthusiast,
clicker-game maker. Built with React + Vite, no template.

## Stack

- React 19 + Vite 7
- Self-hosted fonts: Bricolage Grotesque (display), IBM Plex Mono (mono)
- No CSS framework, no paid services

## Develop

```bash
npm install
npm run dev
```

## Build & deploy

```bash
npm run deploy   # builds and pushes dist/ to gh-pages
```
